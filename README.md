# Attendance Management System

A simple **Python-based Attendance Management System** that allows users to add students, mark their attendance, and view attendance percentages.

## Features

* Add new students
* Mark students as Present or Absent
* Calculate attendance percentage
* View attendance of all students
* Simple menu-driven program
* Runs continuously until the user chooses Exit

## Technologies Used

* Python
* Dictionaries
* Loops
* Conditional Statements
* User Input

## How to Run

1. Install Python on your computer.
2. Save the program as `attendance_management.py`.
3. Open the terminal in the project folder.
4. Run:

```bash
python attendance_management.py
```

## Menu Options

1. **Add Student** – Add a student's roll number and name.
2. **Mark Attendance** – Mark the student as Present or Absent.
3. **View Attendance** – Display attendance percentage for all students.
4. **Exit** – Close the program.

## Attendance Calculation

Attendance percentage is calculated using:

```text
Present Classes / Total Classes × 100
```
