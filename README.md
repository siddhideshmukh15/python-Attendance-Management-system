# Attendance Management System

A simple Python-based Attendance Management System that allows users to manage student attendance.

## Features

* Add Student
* Mark Attendance as Present or Absent
* View Attendance Percentage
* Delete Student
* Exit the program
* Menu-driven interface

## Technologies Used

* Python
* Dictionaries
* Loops
* Conditional Statements
* User Input

## How to Run

1. Install Python.
2. Open the project folder in VS Code or terminal.
3. Run the Python file:

```bash
python attendance_management.py
```

## Menu Options

1. **Add Student** – Add a student's roll number and name.
2. **Mark Attendance** – Mark a student as Present or Absent.
3. **View Attendance** – Display the attendance percentage of all students.
4. **Delete Student** – Remove a student using their roll number.
5. **Exit** – Close the program.

## Attendance Calculation

```text
Attendance Percentage = (Present Classes / Total Classes) × 100
```
